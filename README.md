A faster drop-in for csv-reader 1.0.0: `solve.js` answers exactly as csv-reader does on every broken-CSV case — same columns, rows, and errors — but parses with bulk native scans (one slice + split per plain record, indexOf-driven field boundaries, quoted fields sliced whole unless they need repair) instead of one character at a time.

## Run it

```sh
MAKEFUN_INPUT_DIR=/input MAKEFUN_OUTPUT_DIR=/output node main.ts
```

`main.ts` reads every case from `$MAKEFUN_INPUT_DIR/cases.json`, answers each with `run()` from `solve.js`, and writes `$MAKEFUN_OUTPUT_DIR/answers.json`. No dependencies, no network, deterministic.
